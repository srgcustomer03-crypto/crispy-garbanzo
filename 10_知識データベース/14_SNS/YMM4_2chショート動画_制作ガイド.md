# YMM4で2chショート動画を作る方法

台本「script_01_low_income_revenge.md」を例に、実際の制作手順を解説します。

---

## 事前準備

### 1. 必要なソフト
| ソフト | 用途 | 入手先 |
|--------|------|--------|
| YMM4 | 動画編集 | https://manjubox.net/ymm4/ |
| VOICEVOX | 音声合成 | https://voicevox.hiroshiba.jp/ |
| 立ち絵素材 | キャラ表示 | ニコニコ静画等 |

### 2. 素材フォルダ構成（推奨）
```
動画プロジェクト/
├── 01_画像/
│   ├── 背景/
│   ├── キャラ/
│   └── UI部品/（2chレス枠など）
├── 02_音声/
│   ├── BGM/
│   └── SE/
├── 03_立ち絵/
└── project.ymmp
```

---

## Step 1：プロジェクト設定

### 新規プロジェクト作成
1. YMM4起動 → `ファイル` → `新規プロジェクト`
2. 設定：
   - **解像度**: 1080 x 1920（縦型ショート用）
   - **フレームレート**: 30fps
   - **長さ**: 65秒（余裕を持たせる）

---

## Step 2：キャラクター設定

### 使用キャラ例
| 役割 | キャラ | 声 |
|------|--------|-----|
| ナレーション | ずんだもん | VOICEVOX |
| 俺（主人公） | 四国めたん | VOICEVOX |
| 元カノ | 春日部つむぎ | VOICEVOX |
| スレ民A〜G | 青山龍星/冥鳴ひまり等 | VOICEVOX |
| 妻 | 小夜/SAYO | VOICEVOX |

### キャラ登録手順
1. `キャラクター設定` → `新規作成`
2. 名前：「俺」「元カノ」「ナレ」など
3. ボイス：VOICEVOXの該当キャラを選択
4. 立ち絵：表情差分を登録（通常/怒り/泣き/驚き等）

---

## Step 3：台本をYMM4に入力

### セリフ入力の流れ

台本の時間に合わせてセリフを配置：

```
【0:01】元カノ「ねえ…やり直さない？」
【0:03】俺「…誰？」
【0:04】ナレ「低収入で捨てられた男の"逆転劇"がヤバすぎたwww」
```

### 入力手順
1. タイムライン上で右クリック → `アイテムを追加` → `ボイスアイテム`
2. キャラを選択（例：元カノ）
3. セリフを入力：「ねえ…やり直さない？」
4. `Enter`で音声生成
5. タイムライン上で開始位置を調整（0:01に配置）

### 効率化Tips
- **連続入力**: セリフ入力後 `Ctrl+Enter` で次のセリフへ
- **一括配置**: 全セリフを先に入力 → 後から位置調整

---

## Step 4：画像・背景を配置

### 画像アイテムの追加
1. `アイテムを追加` → `画像アイテム`
2. `script_01_assets.csv`の画像を選択
3. 表示時間をセリフに合わせる

### 時間別の画像配置（台本より）

| 時間 | 配置する画像 |
|------|-------------|
| 0:01-0:03 | 元カノ泣き顔（紫背景） |
| 0:03-0:05 | 俺の余裕顔（青背景） |
| 0:06-0:08 | 給与明細を見る男 |
| 0:08-0:12 | 女の冷たい表情 |
| ... | ... |

### 画像の動き（重要！）
静止画をそのまま見せない → **常に動きをつける**

1. 画像を選択 → `エフェクト` → `登場`
2. おすすめエフェクト：
   - **ズームイン**: 1.0 → 1.1（2秒かけて）
   - **左右に揺れる**: 振幅5px
   - **フェードイン**: 0.3秒

---

## Step 5：字幕・テロップ設定

### 基本字幕（セリフ表示）
1. `表示設定` → `字幕` → ON
2. フォント設定：
   - **通常セリフ**: Noto Sans JP Bold / 48pt
   - **感情セリフ**: ラグランパンチ / 72pt（赤+黒縁）

### 強調テロップの追加
重要なセリフは別途テロップで強調：

1. `アイテムを追加` → `テキストアイテム`
2. 例：「年収1000万」「借金300万」
3. 設定：
   - フォント: 極太ゴシック
   - サイズ: 100pt以上
   - 色: 赤 + 黒縁取り（5px）
   - エフェクト: `登場` → `ドン！`（拡大して登場）

### 2chレス風テロップ
スレ民のコメントは専用スタイルで：

```
┌────────────────────┐
│ 12: 名無しさん      │
│ 胸糞悪すぎて草      │
└────────────────────┘
```

1. 背景付きテキストボックスを作成
2. または画像素材として用意しておく

---

## Step 6：BGM・SE配置

### BGM配置（感情曲線に合わせる）

| 時間 | BGMの雰囲気 | 配置 |
|------|-------------|------|
| 0:00-0:05 | 衝撃音→無音 | SE「ドンッ」のみ |
| 0:05-0:30 | どんよりピアノ | 悲しいBGM |
| 0:30-0:50 | テンポアップ | 明るいBGMに切替 |
| 0:50-1:00 | 勝利・爽快系 | アップテンポBGM |

### SE配置
| 時間 | SE |
|------|-----|
| 0:00 | ドンッ（衝撃音） |
| 0:20 | ドアが閉まる音 |
| 0:29 | 時計の針が回る音 |
| 0:39 | LINE通知音（ピロン） |
| 0:58 | 靴音（カツカツ） |

### BGM・SE入手先
- DOVA-SYNDROME（フリーBGM）
- 効果音ラボ（フリーSE）
- 甘茶の音楽工房

---

## Step 7：仕上げ・書き出し

### 最終チェック項目
- [ ] セリフと画像のタイミングは合っているか
- [ ] 無音部分がないか（ジャンプカット確認）
- [ ] 字幕が読みやすいか
- [ ] BGMの音量バランス（セリフの邪魔にならないか）
- [ ] 60秒以内に収まっているか

### 書き出し設定
1. `ファイル` → `動画出力`
2. 設定：
   - **形式**: MP4（H.264）
   - **解像度**: 1080 x 1920
   - **ビットレート**: 8000kbps以上
   - **音声**: AAC 192kbps

---

## 時短テクニック

### 1. テンプレート化
よく使う設定をテンプレートとして保存：
- キャラ設定
- 字幕スタイル
- 2chレス枠
- BGMフェード設定

### 2. セリフ一括入力
台本をテキストファイルで用意 → YMM4にドラッグ&ドロップで一括読み込み

### 3. 立ち絵表情の自動切替
感情タグを設定しておくと、セリフに応じて自動で表情が変わる

---

## トラブルシューティング

| 問題 | 解決策 |
|------|--------|
| 音声が生成されない | VOICEVOXが起動しているか確認 |
| 動画が重い | プレビュー画質を下げる |
| 書き出しが遅い | GPUエンコードを有効化 |
| 縦動画にならない | プロジェクト設定で1080x1920を確認 |

## 制作時間の目安

| 工程 | 時間 |
|------|------|
| 素材収集 | 30分〜1時間 |
| セリフ入力 | 20分 |
| 画像配置 | 30分 |
| BGM・SE配置 | 15分 |
| 調整・仕上げ | 30分 |
| **合計** | **約2〜3時間** |

慣れれば1本1時間程度で制作可能。
