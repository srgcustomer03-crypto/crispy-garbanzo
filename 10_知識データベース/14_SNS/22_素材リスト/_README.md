# 22_素材リスト

## 概要
各台本に必要な画像素材のリスト（いらすとやURL・AI生成プロンプト）を格納するフォルダ

## 命名規則
```
script_[番号]_assets.csv
```
例：`script_01_assets.csv`

## CSV列構成
| 列名 | 説明 |
|------|------|
| シーン | 導入/展開①/転換/オチなど |
| 時間 | 秒数（例：0:32） |
| 用途 | 何を表現するか |
| AI画像プロンプト | ChatGPT/Midjourney用（英語） |
| いらすとやURL | 該当素材のURL |
| いらすとや素材名 | 素材の名前 |
| 備考 | 追加演出・色調指示など |

## 収録ファイル
| ファイル名 | 対応台本 |
|-----------|----------|
| script_01_assets.csv | script_01_low_income_revenge.md |
