# 21_詳細台本

## 概要
採用した台本案の詳細版（秒単位のセリフ・演出指示付き）を格納するフォルダ

## 命名規則
```
script_[番号]_[内容の英語略称].md
```
例：`script_01_low_income_revenge.md`

## 収録ファイル
| ファイル名 | 対応案 | 内容 |
|-----------|--------|------|
| script_01_low_income_revenge.md | 案1.2 | 低収入で捨てられた男の逆転劇 |
| script_01_pc_water_damage.md | 案1.1 | PC水没させた甥っ子 |

## 台本フォーマット
- 導入（0-5秒）：フック
- 展開（5-35秒）：ヘイト管理
- 転換（35-50秒）：ヒーロー登場
- オチ（50-60秒）：カタルシス
